* Claude-code ide
** Required packages
- vterm: installed in ~defaults.org~
- ghostel: Ghostel is a terminal emulator for Emacs powered by
  libghostty-vt, the VT engine behind the Ghostty terminal.
** Installation
#+begin_src emacs-lisp
  (use-package claude-code-ide
    :straight (:type git :host github :repo "manzaltu/claude-code-ide.el")
    :bind ("C-c C-'" . claude-code-ide-menu) ; Set your favorite keybinding
    :config
    (setq claude-code-ide-cli-path (expand-file-name "~/.local/bin/claude"))
    (setq claude-code-ide-terminal-backend 'vterm)
    (claude-code-ide-emacs-tools-setup)) ; Optionally enable Emacs MCP tools  
#+end_src
